Café Aurora - Notificaciones con Toastify

Esta práctica integra la librería externa Toastify-js cargada por CDN. Los botones disparan notificaciones tipo "toast" (mensajes flotantes no bloqueantes) de éxito y de error, sin escribir JavaScript dentro del HTML.

Notificaciones tipo toast

Cada botón llama a Toastify para mostrar un aviso breve que aparece en la esquina de la pantalla y desaparece solo.

Carga dinámica de una librería

Este botón inserta un tag <script> en tiempo de ejecución para cargar una librería adicional (Day.js) y, recién cuando termina de descargarse (evento onload), la usa para mostrar la fecha y hora actual en un toast.

Si el CDN principal de Toastify no responde, la página carga una copia de respaldo (fallback) automáticamente. La lógica completa vive en app.js.
