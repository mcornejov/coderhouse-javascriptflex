# Curso de JavaScript Flex — CoderHouse

Entregas del curso de JavaScript Flex: las 14 prácticas por unidad y la Evaluación Final.

**Autor:** Miguel Cornejo

## Sitio en vivo

**https://mcornejov.github.io/coderhouse-javascriptflex/**

Desde el índice se accede al simulador de la Evaluación Final (desplegado y funcionando)
y a cada práctica con su código y su documento.

## Evaluación Final — Simulador Café Aurora

Tienda de bebidas que simula el circuito completo de compra: catálogo cargado con `fetch`
desde un JSON, carrito, totales con recargo y descuento, historial de compras y
notificaciones con SweetAlert2.

- Demo en vivo: **https://mcornejov.github.io/coderhouse-javascriptflex/evaluacion-final/**
- Código: carpeta [`evaluacion-final/`](evaluacion-final/)

## Ejecutar las prácticas de consola en local

```bash
cd practicas/Practica01_Arrays_Mutar
node manipularArrays.js
```

Las prácticas de navegador (12 a 14) y el simulador se abren con un servidor local
(por ejemplo, la extensión Live Server de VS Code) o directamente desde el sitio en vivo.
